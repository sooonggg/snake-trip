## 專案介紹

「地頭蛇來蛇去」是一個雙北出遊行程規劃網站。選擇出遊日期、時間、地區、交通方式、預算與活動喜好後，可以探索已收錄的 30 個真實地點，並組合成自己的小旅行。平日、週末、下課或下班後都能規劃。

## 主要功能

- 依日期、時間、縣市、行政區、預算及喜好篩選地點。
- 收錄咖啡廳、美食、散步、文化景點、自然景點與夜景。
- 依已收錄營業資料檢查公休、可安排時段與待確認資訊。
- 自動產生行程，也可以自行加入地點。
- 鎖定、替換、移除、調整順序及停留時間。
- 收藏地點、儲存行程，並複製行程文字。
- 開啟地點來源與 Google Maps 查詢交通。
- 響應式版面，支援手機與電腦。

## 使用方式

1. 選擇出發日期、開始與結束時間。
2. 設定地區、交通方式、預算與喜歡的活動。
3. 點選「讓地頭蛇幫我排」，或從地點卡片逐一加入行程。
4. 鎖定喜歡的站點，調整其他地點、順序與停留時間。
5. 儲存或複製行程，出發前再次確認營業與交通資訊。

## 檔案與技術

```text
snake-trip/
├── index.html   # 可操作的完整網頁
└── README.md    # 專案說明與網站連結
```

網頁採用原生 HTML、CSS、JavaScript。樣式、互動程式、SVG 插圖與地點資料均包含在單一 `index.html` 中，無須建置工具或後端伺服器。收藏與行程使用瀏覽器的 `localStorage` 儲存。

## 資料說明

- 地點採事先整理的精選資料，並非即時搜尋 IG、Threads 或最新熱門排行。
- 各地點附資料來源及查核日期；缺少營業或費用資訊時會顯示待確認。
- 「預計營業」依已收錄時段判斷，特殊節日、臨時店休、候位與訂位狀況請再向店家確認。
- 移動時間為估算；費用小計不含交通、購物及未確認費用。
- 插圖為原創分類示意，非店家實景。
- 收藏只保留在目前瀏覽器，清除網站資料後會移除，不提供跨裝置同步。
